# 📚 Bookstore  
### Online Bookstore (Mini Project)

Bookstore คือเว็บร้านขายหนังสือออนไลน์แบบเรียบง่าย  
พัฒนาขึ้นเพื่อใช้เป็น **Mini Project** โดยเน้นการใช้งานพื้นฐานของร้านค้าออนไลน์  
ผู้ใช้สามารถดูรายการหนังสือ ดูรายละเอียด เพิ่มหนังสือลงตะกร้า  
คำนวณราคารวม และล้างตะกร้าได้  
**ระบบนี้ไม่มีขั้นตอนการชำระเงิน (Checkout / Payment)**

---

## 📋 Project Overview
ระบบร้านหนังสือออนไลน์ขนาดเล็ก  
สำหรับแสดงรายการหนังสือและจำลองการสั่งซื้อผ่านตะกร้าสินค้า  
เหมาะสำหรับการฝึกพัฒนา Web Application ด้วย Next.js และ Supabase

---

## 🛠 Tech Stack
- **Frontend**: Next.js (React)
- **Backend / Database**: Supabase (PostgreSQL)

---

## ✨ Features

### 📖 Book Catalog
- แสดงรายการหนังสือทั้งหมด
- แสดงข้อมูลหนังสือ:
  - ชื่อหนังสือ
  - ผู้แต่ง
  - หมวดหมู่
  - ราคา
  - รูปภาพปกหนังสือ

---

### 📄 Book Detail
- ดูรายละเอียดหนังสือแต่ละเล่ม
- แสดงข้อมูล:
  - รายละเอียดหนังสือ
  - ราคา
  - รูปภาพ
- ปุ่มเพิ่มหนังสือลงตะกร้า

---

### 🛒 Shopping Cart
- เพิ่มหนังสือลงตะกร้า
- แสดงรายการหนังสือในตะกร้า
- แก้ไขจำนวนหนังสือในตะกร้า
- ลบหนังสือออกจากตะกร้า
- คำนวณราคารวมทั้งหมด
- ล้างตะกร้าสินค้าได้

---

### ❌ No Payment System
- ระบบ **ไม่มีหน้า Checkout**
- ไม่มีการชำระเงินจริง
- ตะกร้าใช้เพื่อการจำลองการซื้อเท่านั้น
